# 翻页小书图标

原创矢量几何，由 `tools/make_app_icon.py` 生成；青绿色封面、浅色书页及抬起的翻页。
SVG 为可编辑源图，PNG 供 Tk 窗口使用，ICO 包含 16–256 像素尺寸供 Windows 可执行文件、标题栏和任务栏使用。生成时使用本机已有 Pillow，运行软件不增加依赖。

样式调研参考 Lucide 的 [book-open](https://lucide.dev/icons/book-open) 以及其 [ISC 许可证](https://github.com/lucide-icons/lucide/blob/main/LICENSE)。未复制其 SVG 路径，实际图标为本项目自绘，无付费素材。
